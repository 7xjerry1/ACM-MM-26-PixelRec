# PixelRec: From Modality-Level Fusion to Signal-Patch-Level Fusion for Multimodal Sequential Recommendation

This is the official repository for **PixelRec: From Modality-Level Fusion to Signal-Patch-Level Fusion for Multimodal Sequential Recommendation**, accepted at **ACM MM '26**.

## Overview

PixelRec revisits multimodal sequential recommendation from a fine-grained fusion perspective. Instead of treating text and image features as coarse modality-level units, PixelRec transforms textual content into visualized text, combines it with item images as a unified visual input, and performs recommendation by modeling signal-patch-level multimodal information.

## Highlights

- A signal-patch-level multimodal recommendation framework for sequential recommendation.
- A unified visual input design that bridges textual and visual item content.
- Adaptive fine-grained fusion for capturing complementary multimodal signals.
